# weather-app
Weather App Description:

This weather app is built using HTML, CSS, and JavaScript. It allows users to check real-time weather information by entering a city name. When a valid city is entered, the app displays key weather details such as temperature, weather condition (e.g., sunny, cloudy), and humidity. If an invalid city name is entered, the app notifies the user with an "Invalid city name" message, ensuring smooth and user-friendly interaction.

Key Features:
City-Based Weather Search:
Users can enter the name of any city in the input field. Upon submission, the app sends a request to the weather API and retrieves weather data for the specified location.

Real-Time Weather Information:
When a valid city name is entered, the app displays current weather details, including:

Temperature (in degrees Celsius or Fahrenheit)

Weather Condition (e.g., sunny, rainy, cloudy)

Humidity level (in percentage)

Error Handling for Invalid Input:
If the user enters an invalid or misspelled city name, the app gracefully handles the error by displaying a clear "Invalid city name" message, prompting the user to try again.

Use Cases:
Quickly check weather conditions before travel.

Learn weather details in any city around the world.
